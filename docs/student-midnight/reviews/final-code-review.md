## Initial findings — both resolved in scoped re-review

1. **P2 — Delayed profile loading leaves Midnight Account fields empty and can replace saved choices.** `app/page.tsx:652` mounts the Midnight `StudentProfileEditor` with `key={userId}`. The same editor initializes its name/year/avatar state from its first profile prop only (`app/page.tsx:657`). Theme loading finishes independently of the aggregate course/profile `load()` (`app/page.tsx:197`), so a student can open Account after their Midnight preference loads but before their profile arrives. The editor first mounts with `undefined`; when the profile arrives, its stable user-ID key preserves empty name/year and the default book avatar. The identity card updates, but the editable fields do not. Filling the name and saving can overwrite the previously saved year/avatar with those defaults. The Light path already handles this transition with a missing-profile fallback key that changes to the loaded profile ID. Preserve that readiness transition in Midnight or defer mounting the editor until its profile exists, and add a delayed-profile integration regression. An ephemeral check transpiling the actual editor and retaining its hook slots across `undefined` → populated profile confirmed `['', '', 'book']` despite the supplied saved name, Year 10 and rocket avatar. This was a deterministic component-state check, not a browser test.

2. **P2 — Midnight Progress omits the real completed/total lesson counts available in Light.** `app/MidnightScreens.tsx:23–24` only receives/renders each course's rounded percentage. The existing Light Progress branch at `app/page.tsx:647` also shows `X of Y lessons completed`. A percentage cannot reproduce those values, so this fails the approved requirement that both themes expose the same information. Pass shared completion counts into the Midnight presentation and retain them in the course completion row. Add a parity regression with nontrivial completed/total values; none of the three current screen render tests exercise `MidnightProgress`.
